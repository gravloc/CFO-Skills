description: Organise the financial section of the investor data room and prepare investor updates' numbers. Use before investor meetings or when asked for diligence materials.
---
## Steps
1. Create a checklist in Drive: financial model, budget, cap table summary,
   use of funds, key metrics, pricing assumptions, risks.
2. Check numbers against sources and each other; all figures dated.
3. Mark restricted files; sharing needs founder approval each time.
4. For monthly investor updates, supply the finance block (runway, burn,
   spend vs plan, key assumptions changed) to the CEO's investor-update skill.
5. Never share links or files externally.
