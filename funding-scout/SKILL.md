## Steps
1. Search official sources in the browser (government programmes,
   incubators, space agencies and funds, accelerators, cloud/AI credit
   programmes). Never rely on memory for eligibility, amounts or deadlines.
2. For each: name, funder, amount, eligibility, deadline, effort to apply,
   fit with GRAVLOC (space, India, early stage), source URL and date checked.
3. Rank by fit and effort. Note anything needing entity status or
   recognition we may not have.
4. Create Linear issues for the top picks with deadlines.
5. Draft application text for the founder's review. Never submit. Flag
   any claims in applications that need proof.
